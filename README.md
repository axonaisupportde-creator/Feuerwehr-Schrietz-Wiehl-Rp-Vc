# Feuerwehr Schrietz Wiehl

Statische Website für die Roblox-Feuerwehr-Roleplay-Community **Feuerwehr Schrietz Wiehl**.

## Struktur

```
Feuerwehr-Schrietz-Wiehl/
├── index.html          Startseite mit allen Bereichen und Film-Abspann
├── impressum.html      Impressum
├── datenschutz.html    Datenschutzhinweise
├── css/style.css       Gesamtes Design, Animationen, Responsive Layout
├── js/main.js          Navigation, Scroll-Animationen, Counter, Abspann-Steuerung
└── assets/favicon.svg  Favicon
```

## Veröffentlichen

1. ZIP entpacken.
2. Alle Dateien in ein GitHub-Repository hochladen (der Ordnerinhalt gehört in das Wurzelverzeichnis).
3. Unter **Settings → Pages** den Branch `main` und den Ordner `/ (root)` auswählen.

Es ist kein Build-Schritt und keine Installation nötig – die Website läuft direkt im Browser.
